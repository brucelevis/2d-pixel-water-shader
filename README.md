# UE 5.7 migration workspace

Open `PixelWaterUE57.uproject` in UE 5.7. To have the editor create native assets, run `Tools/build_ue_project.py` from its Python console (Window → Developer Tools → Output Log, then `py "<absolute path>/Tools/build_ue_project.py"`). It imports the original PNGs, attempts to create a Custom-node water material and sand material, and creates a simple orthographic preview level. Inspect the material compiler output after generation; editor scripting APIs and Custom HLSL texture input behavior can vary, and generated assets require validation in UE 5.7.

The original Unity source assets remain unchanged under `Assets/`. Unity `.unity`, `.shadergraph`, `.mat`, Tilemap, and Prefab files are not UE `.uasset` files. This automated setup is a starting point for in-editor reconstruction, not a proven pixel-identical conversion. Upstream notes that heightmap-generation code is not included, so exact heightmap-driven foam cannot be reproduced from the supplied source alone.
